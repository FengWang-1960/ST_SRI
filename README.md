# ST-SRI: BSPC revision code and scientific evidence

This repository is the versioned delivery entry for the BSPC revision of **ST-SRI: A Protocol-Defined Current--History Interaction Audit for Surface Electromyography Intent Recognition**.

## Evidence release in preparation

The fixed `closeout-v4p1-b16` archive (2026-10-10) contains the original closeout-v4 evidence, the versioned v4p1 verifier, source and model identity records, saved results, original execution records, and a self-contained S01 inference demonstration. Code and evidence are distributed together in the release archive.

Release upload and public-download verification are in progress. A verified version URL will be added here after publication.

## Verification scope

The retained macOS saved-result checks passed portable and strict modes (27,396 checks each); the recorded Linux strict failure remains part of the evidence. Portable acceptance uses the declared numerical tolerances and exact discrete/identity checks. S01 execution receipts cover one released model and input, not all DB2 inference or model training.

Raw NinaPro recordings remain an external input. The archive retains historical manuscript snapshots for provenance; current submission documents are managed separately.

The study distinguishes continuous interaction strength, raw maximum position and empirical reference exceedance. The DB2 application remains a development-informed case study, and its empirical reference rule is not calibrated false-positive control.
